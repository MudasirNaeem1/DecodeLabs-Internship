Database Schema — SQLite
TABLE users
PK user_id INTEGER NOT NULL
   name TEXT NOT NULL
   email TEXT UNIQUE NOT NULL
   status TEXT DEFAULT 'active'
              CHECK IN ('active','inactive')
   created_at DATETIME
TABLE orders
PK order_id INTEGER NOT NULL
FK user_id INTEGER → users(user_id)
   amount REAL CHECK(amount > 0)
   created_at DATETIME
  
FOREIGN KEY (user_id)
  REFERENCES users(user_id)
🔗 Relationship: users → orders is One-to-Many (1:M) — one user can have many orders
🛡️ Integrity: Deleting a user with active orders is blocked by FK constraint
🔒 Security: All queries use parameterized placeholders ? — SQL injection safe
